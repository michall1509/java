1. W jaki sposób można określić właściwość danego obiektu (dwa sposoby wraz z przykładami)?

Właściwość danego obiektu można określić na dwa sposoby.

Sposób 1 – notacja kropkowa
nazwa_obiektu.nazwa_właściwości = wartość; 


auto.marka = "Opel Omega";
auto.rok = 1996;
auto.cena = 25000;

Sposób 2 – notacja tablicowa
nazwa_obiektu["nazwa_właściwości"] = wartość; 


auto["cena"] = 25000;

2. W jaki sposób można odwołać się do pól (właściwości) i metod?

Do pól i metod obiektu odwołujemy się, podając nazwę obiektu oraz kropkę, a następnie nazwę właściwości lub metody. 


console.log(samochod1.kolor);
samochod1.jedz();

3. Wymień cechy charakterystyczne konstruktora

Cechy charakterystyczne konstruktora:

– jest wywoływany automatycznie podczas tworzenia obiektu,
– ma taką samą nazwę jak klasa (funkcja),
– nie zwraca wartości,
– może przyjmować argumenty,
– do tworzenia obiektu używa się słowa kluczowego new.

4. Konstruowanie obiektu – obiekt ma trzy pola oraz jedną metodę


var osoba_1 = {
    nazwisko: 'Kowalski',
    imie: 'Jan',
    zawod: 'piekarz',
    wyswietl: function() {
        document.write(this.nazwisko + ' ' + this.imie);
    }
}

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

Słowo kluczowe this pozwala odwołać się do pola lub metody obiektu z wnętrza tego obiektu.

Pola i metody w obiekcie oddzielamy przecinkami.

6. Konstruktor w JavaScript – przykład wraz z opisem


function klient(nazwisko_k, imie_k, zawod_k) {
    this.nazwisko = nazwisko_k;
    this.imie = imie_k;
    this.zawod = zawod_k;

    this.wypisz = function() {
        alert(this.nazwisko + ' ' + this.imie);
    }
}

Funkcja pełni rolę konstruktora. Słowo this odnosi się do aktualnie tworzonego obiektu i pozwala przypisać mu właściwości oraz metody.

7. Znaczenie słowa kluczowego new wraz z przykładem

Słowo kluczowe new służy do tworzenia nowego obiektu na podstawie konstruktora. 


var osoba1 = new klient('Kowalski', 'Jan', 'kierowca');
var osoba2 = new klient('Nowak', 'Anna', 'sekretarka');

Powstają dwa różne obiekty utworzone na podstawie tego samego konstruktora.

8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem

Właściwość prototype służy do dodawania metod i właściwości wspólnych dla wszystkich obiektów tworzonych na podstawie danego konstruktora. 


function klient() {
    this.nazwisko = 'Bielski';
    this.imie = 'Paweł';
}

klient.prototype.pisz_dane = function() {
    document.write(this.nazwisko + ' ' + this.imie);
}

klient.prototype.zawod = 'kierowca';

var osoba1 = new klient();
osoba1.pisz_dane();

Metoda oraz właściwość dodane przez prototype są dostępne dla wszystkich obiektów utworzonych na podstawie konstruktora.
