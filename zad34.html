Zadanie 34 - Instrukcje warunkowe

1) Instrukcja wyboru – składnia teoretyczna

Jest to instrukcja if, która sprawdza czy dany warunek jest prawdziwy.

if (warunek) { 
  // kod do wykonania
}
2) Instrukcja wyboru – schemat blokowy 
      [ START ]
          |
     < WARUNEK? > --- NIE ---> [ KONIEC ]
          |
         TAK
          |
    [ INSTRUKCJA ]
          |
      [ KONIEC ]
3) Instrukcja alternatywy – składnia teoretyczna

Instrukcja if...else pozwala wykonać jeden blok kodu gdy warunek jest spełniony, a drugi gdy nie jest.

if (warunek) { 
  // blok gdy prawda 
} else { 
  // blok gdy fałsz 
}
4) Instrukcja alternatywy – schemat blokowy 
           |
      < WARUNEK? >
      /          \
    TAK          NIE
     |            |
 [ BLOK A ]   [ BLOK B ]
      \          /
       [ KONIEC ]
5) Operatory porównania

== sprawdza czy wartości są równe

!= sprawdza czy wartości są różne

< oraz > to mniejszość i większość

<= oraz >= to mniejszy/większy lub równy

6) Uwaga do operatorów porównania

Należy pamiętać, że pojedynczy znak "=" służy do przypisywania wartości do zmiennej, natomiast podwójny znak "==" służy do porównywania dwóch wartości ze sobą.

7) Operatory logiczne

&& (AND) - obie części muszą być prawdziwe.

|| (OR) - wystarczy, że jedna część jest prawdziwa.

! (NOT) - zaprzeczenie, zmienia prawdę w fałsz.
